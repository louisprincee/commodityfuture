## 3. 单因子两端入场与中位数缓冲对照（`buffer`，原第 10.4 节）

两端各约 30% 入场、穿过中位数退出（全市场 ≥ 8 品种，板块中性每板块 ≥ 5 品种），`delay=0`、`1 tick` 滑点结果：

| 因子与得分 | 日换手，无缓冲 → 有缓冲 | 年化净收益，无缓冲 → 有缓冲 |
|---|---:|---:|
| 空仓增量反号 `K_DS`，原值 | 267.3% → 204.5% | −13.35% → −10.27% |
| 空仓增量反号 `K_DS`，去均值 | 266.5% → 208.3% | −11.30% → −7.57% |
| 空仓增量反号 `K_DS`，z-score | 279.6% → 209.8% | −14.90% → −10.38% |
| `CROWD1` z-score | 156.3% → 96.6% | −13.57% → −8.42% |
| 严格 `POWER_20` z-score | 15.1% → 11.7% | +1.19% → −2.00% |
| 填补 `POWER_20_FILLED` z-score | 117.9% → 75.7% | −9.26% → −2.60% |
| `K_NET_60` z-score | 65.3% → 35.9% | −3.05% → −0.66% |
| `FLOW_CONTROL` z-score | 283.0% → 214.4% | −14.92% → −7.73% |

结论：单因子截面多空即使引入中位数缓冲，全市场日换手仍高达 35.9%–214.4%，成本继续覆盖毛收益；板块中性因小池进出跳动换手更高。

## 5. 单品种五日择时与事件时机审计（`timing` / `event-timing`，原第 13、15 节）

- **第 13 节单品种五日择时（t+2 执行，5 个偏移中位数）**：填补版 20 日合力单品种择时净夏普 **+0.77**（期末 1,164.33 万元，年化 +2.58%，日换手 10.5%），优于同预算截面对照（+0.58）与严格版（+0.30）；`FLOW`（−0.60）、空仓变动（−0.24）、有色共振扩展到无覆盖门槛后（−0.26）与化工反转延迟（−0.25）均告负。
- **第 15 节事件时机与方向分解**：
  - 11,231 次可交易空仓冲击在首日净均值为 +0.28 bp（毛收益 +8.48 bp），其中 **多头腿首日净均值 +8.36 bp、第 2–5 日额外毛收益 +29.91 bp**，而 **空头腿首日净均值 −8.26 bp、第 2–5 日 −16.34 bp**，揭示了空仓冲击的收益高度集中于多头端（`short_shock == +1`），且 2 ticks 与延迟一日均使双边组合转亏。
  - 拥挤度 1 反转的 803 次事件收益集中于螺纹钢 38 次样本，剔除后首日净均值由 +2.60 bp 降至 −2.26 bp；且由“前 20 名绝对规模 + 1/N 闲置资金”导致敞口过低（`power_filled` 仅 25.6%，`short_shock` 仅 16.6%，保证金占用仅 1.8%–2.7%）。
