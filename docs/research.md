# 商品期货会员持仓因子研究

## 一、研究设定

### 1.1 品种池与时序

每日收盘后重算流动性池：过去 242 个交易日成交额中位数达到 5 亿元、当日主力合约有效成交且收益合法的品种进入截面。对历史更名品种保留旧代码合约直至最后交易日，统一乘数口径并映射至研究标的，不改写原始成交价。

因子只使用当日收盘已知的行情与榜单。权重于次日开盘成交。前瞻收益按同一实际合约开盘价复利，跨换月不引入价差跳变。截面 IC 为每日截面 Spearman 相关；时间序列显著性用 Newey–West HAC 标准误，并在事先划定的检验族内做 Benjamini–Hochberg 校正。

### 1.2 回测执行

纯会员策略与等权多头基准在统一账本上按整数手运行。

| 维度 | 规则 |
| --- | --- |
| 资金与头寸 | 初始 1,000 万空仓；目标权重乘数 2.0，基准为 1.0；单品种上限 20%，基准为 10%；统一保证金率 20%，总保证金上限 50% |
| 成交与费用 | 次日开盘成交、结算盯市；换月先平旧再开新并双边计费；主报告按单边 1 跳滑点，2 跳结果另存 |
| 历史手续费 | 优先取逐日实际费率；早期缺失按同合约前值优先、同品种此前无冲突最近费率次之承接；严禁未来倒填 |
| 容量与退出 | 单日开平容量为合约截至昨日过去 20 日中位成交量的 1%；建仓上限为 3 日平仓容量；到期前最后 5 个交易日停开并强制清仓 |

## 二、会员持仓因子定义

交易所每日公布多头、空头与成交前 20 名席位。记品种 \(i\)、交易日 \(t\)、会员 \(j\) 的多头持仓为 \(L_{j,t}\)、空头持仓为 \(S_{j,t}\)、披露增减量为 \(\Delta L_{j,t}\)、\(\Delta S_{j,t}\)，成交榜成交量为 \(V_{j,t}\)，市场单边总持仓与总成交量为 \(OI_{i,t}\)、\(VOL_{i,t}\)。

可见持仓与净头寸定义为

\[
G_{j,t}=L_{j,t}+S_{j,t},\qquad N_{j,t}=L_{j,t}-S_{j,t}.
\]

一侧未上榜时，该侧按可见口径记为零。

### 2.1 粘性与高换手分组

席位换手率与市场换手率分别为

\[
\tau_{j,t}=\frac{V_{j,t}}{G_{j,t}},\qquad \tau^{m}_{i,t}=\frac{VOL_{i,t}}{OI_{i,t}}.
\]

高换手组 \(\mathcal{H}_{i,t}\) 为有可见持仓且上成交榜、且 \(\tau_{j,t}\ge\tau^{m}_{i,t}\) 的席位；其余有持仓的席位归入粘性组 \(\mathcal{P}_{i,t}\)，包括未上成交榜的席位。

粘性席位净多占比为

\[
\operatorname{STICKY\_NET\_SHARE}_{i,t}
=\frac{\sum_{j\in\mathcal{P}_{i,t}}N_{j,t}}{\sum_{j\in\mathcal{P}_{i,t}}G_{j,t}}.
\]

高换手组内同口径结果记为 \(\operatorname{SPEC\_NET\_SHARE}_{i,t}\)。

经济假设是：相对低换手席位的持仓需求更稳定，其方向可能比短期交易活跃度更有持续性；预测方向由研究期 IC 检验确认。

### 2.2 全榜持仓流对照

全榜会员净增持用于检验粘性席位的流量信息是否具有组别特征：

\[
\operatorname{FLOW\_CONTROL}_{i,t}
=\frac{\sum_j\Delta L_{j,t}-\sum_j\Delta S_{j,t}}{OI_{i,t}}.
\]

任一应披露增减量缺失时，该侧合计无效，不补零。

5 日流变化为 \(\operatorname{FLOW\_CHANGE5}_{i,t}=\operatorname{FLOW\_CONTROL}_{i,t}-\operatorname{FLOW\_CONTROL}_{i,t-5}\)。

### 2.3 持续持仓与粘性身份

经济假设是：持续承担同一方向头寸、且长期换手较低的席位，可能对应更稳定的交易或风险管理需求。身份因子同时约束长期行为与近期方向，不直接识别客户类型。

**持久同向** \(\operatorname{STICKY\_PERSIST}\)：今日有持仓，最近 20 日（含当日）每天至少在一侧持仓榜上榜，并满足

\[
H_{j,t}=1,\qquad\sum_{u=0}^{19}R_{j,t-u}=20,\qquad
\left|\frac1{20}\sum_{u=0}^{19}\operatorname{sign}(N_{j,t-u})\right|\ge0.8.
\]

**长期低换手身份** \(\operatorname{STICKY\_IDENTITY}\)：过去 242 日不含当日，上榜持仓天数 \(D^H\) 不少于 60 日，其中属于原粘性组的天数 \(D^P\) 占比不低于 80%：

\[
D^H_{j,t}\ge60,\qquad D^P_{j,t}/D^H_{j,t}\ge0.8.
\]

滚动统计至少需 120 个历史日，今日须有持仓。该筛选仍使用可见榜单口径。

**持久长期粘性身份** \(\operatorname{STICKY\_PERSIST\_IDENTITY}\)：令 \(\mathcal M_{i,t}\) 为上述两类席位的交集，品种分数为

\[
\operatorname{STICKY\_PERSIST\_IDENTITY}_{i,t}
=\frac{\sum_{j\in\mathcal M_{i,t}}N_{j,t}}{\sum_{j\in\mathcal M_{i,t}}G_{j,t}}.
\]

**净敞口过滤对照** \(\operatorname{STICKY\_PERSIST\_PURE}\)：在持久同向席位中，剔除双侧均披露且 \(|N|/G<0.30\) 的席位，用于检查结果对多空头寸相互抵消的敏感性。

### 2.4 粘性席位持仓流

存量净多描述当前暴露，持仓流描述边际方向需求。经济假设是：低换手席位的净增持可能反映逐步建仓或风险管理需求的变化，并与随后价格调整相关；它不是现金流入量，也不意味着增仓必然带来上涨。方向预测力以第三章的前瞻 IC 检验为准。

**原始持仓流**：

\[
\operatorname{STICKY\_FLOW}_{i,t}
=\frac{\sum_{j\in\mathcal P_{i,t}}\Delta L_{j,t}-\sum_{j\in\mathcal P_{i,t}}\Delta S_{j,t}}{OI_{i,t}}.
\]

任一粘性席位应披露的增减量缺失时，该项无效，不补零。以品种总持仓归一化，衡量方向变化的相对规模。

**5 日平滑版本** \(\operatorname{STICKY\_FLOW5}\)：

\[
\operatorname{STICKY\_FLOW5}_{i,t}
=\frac15\sum_{u=0}^{4}\operatorname{STICKY\_FLOW}_{i,t-u},
\]

需 5 个有效观测。用于降低单日披露与调仓噪声，是同一持仓流信息的平滑版本。粘性席位集合每日可变，指标描述当日所选席位的披露净增持。

## 三、研究期因子结果

### 3.1 原定义粘性与高换手

拉长到 2011 年后，两组在前后半段呈镜像切换。

| 共同有效样本，10 日 IC | 2011–2021 | 2011–2015 | 2016–2021 |
| --- | ---: | ---: | ---: |
| 原粘性净多 | +0.0199 | −0.0037 | +0.0396 |
| 原高换手净多 | −0.0030 | +0.0170 | −0.0198 |

![粘性与高换手席位净多的累计截面 IC](../runs/research/member_review/cumulative_ic.png)

固定核心品种或逐一剔除板块后，该转换依然存在。前半段未入成交榜而归入粘性组的席位比例更高，说明单日成交量榜识别低换手席位在早期噪声更大。构成诊断见下图与 [sticky_composition_by_year.csv](../runs/research/member_review/sticky_composition_by_year.csv)。

![2016 年前后符号切换的诊断](../runs/research/member_review/sticky_composition.png)

### 3.2 未披露一侧插补

将缺失侧按当日另一侧末位持仓的 0 / 0.5 / 0.8 / 1.0 倍填充。粘性组四档 IC 窄幅收敛，两两配对差值不显著；高换手组对插补敏感，但各档均不显著。

## 四、当前策略与结果

### 4.1 纯会员策略

| 策略入口 | 账户名 | 排序规则 |
| --- | --- | --- |
| `sticky_net` | `STICKY_NET` | 原粘性席位净多占比 |
| `persist_identity` | `PERSIST_IDENTITY` | 持久长期粘性身份净多占比 |

共同选样与持有规则：当日有效候选不少于 8 个时，两端各取 10%；同分按固定品种顺序处理；每日建立十分之一批次，10 日重叠持有；次日开盘执行。

持久粘性身份先按行为筛席位，再把合格席位的当日持仓聚合到品种：

1. 过去 242 日不含当日，上榜日中至少 80% 属于原粘性组，上榜至少 60 日；
2. 今日有持仓，且通过近期持久同向筛选；
3. 交集内席位计算 \(\sum N/\sum G\)。
